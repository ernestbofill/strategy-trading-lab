# Badge

Pill-shaped count badge from the activity bar (`badge.*`, `activityBarBadge.*`).

**Consumer provides:** a `<span class="cp-badge">` holding a number (cap at `99+`) or a word of at most four letters.

- Default: `badge` fill, `on-badge` text, `caption` weight 600, `radius-pill`.
- `cp-badge--progress`: `hot-pink` fill for "new" or in-progress markers.

Use badges on icons and tabs only, not inline in body text.
